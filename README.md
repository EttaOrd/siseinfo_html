Siin olevad html failid on puhas teksti html; kasutaja autentimist jms siin ei ole. See on lihtsalt kergeks copy-paste'imiseks.

Regilaule saaks veel juurde panna, aga ma peaks üle küsima, milliseid peaks panema


Converter kaustas on programm, mis paneb tavatekstilise laulu html formaati. 
Juhised: 
- Pane tavateksilised sõnad faili "input.txt" 
- Panne "Main.java" käima
- Tulemus tekib "output.txt" faili. 
NB! Esimene rida "output.txt" failis on sisukorra jaoks, seda ära laulude hulka pane!
